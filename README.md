# CLI Calculator

A simple Command Line Interface (CLI) Calculator built using Node.js and Inquirer.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Interactive CLI
- Repeat calculation
- Arrow key menu

## Technologies Used

- Node.js
- JavaScript
- Inquirer

## Installation

```bash
npm install
```

## Run

```bash
node index.js
```
