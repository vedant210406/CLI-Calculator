# 🧮 CLI Calculator

A simple Command Line Interface (CLI) Calculator built Using **Node.js** and **Inquirer**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📋 Interactive CLI Menu
- 🔄 Repeat Calculation Option
- ⌨️ Arrow Key Navigation

## 🛠️ Technologies Used

- Node.js
- JavaScript (ES6)
- Inquirer
- npm

## 📂 Project Structure

```
CLI-Calculator/
│── .gitignore
│── README.md
│── index.js
│── package.json
└── package-lock.json
```

## 🚀 Installation

```bash
npm install
```

## ▶️ Run the Project

```bash
node index.js
```
